# EEEM068 Human Sentiment Analysis

Group project for EEEM068 Applied Machine Learning.

## Dataset
Using the English-German (En-De) portion of the MSCTD dataset.

## Project goal
Build sentiment classification models using:
- face-based analysis
- full-image analysis
- fusion of both
